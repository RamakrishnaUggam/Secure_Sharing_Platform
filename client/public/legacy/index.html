About
Secure Share is a web-based secure file sharing platform designed to help users safely upload, store, and share files while maintaining complete control over their data. The platform focuses on end-to-end security, simplicity, and accessibility, using only free and widely adopted technologies. The frontend is built using plain HTML, CSS, and JavaScript, ensuring lightweight performance and compatibility across browsers. The backend is developed with Node.js and Express, handling secure API requests, file metadata management, and access control. MongoDB, accessed through Mongoose, is used to store user details and file metadata efficiently. For authentication, the system integrates Firebase Authentication on the client side, while firebase-admin is used on the backend to verify user identity and protect API endpoints. Files are encrypted on the client side using AES encryption before upload and decrypted in the browser after download, ensuring that sensitive data is never exposed to the server or storage provider. With features such as encrypted uploads, secure link-based sharing, integrity verification, and an intuitive dashboard, Secure Share provides a reliable solution for personal, academic, and small-scale file management while offering a strong foundation for future scalability.
